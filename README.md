# Spotify UI Clone - Projeto de Estudo

Este é um projeto de estudo voltado para a replicação de algumas telas do aplicativo **Spotify** no iOS. O principal objetivo é praticar e consolidar os conhecimentos em diferentes abordagens de construção de interfaces de usuário e arquitetura no ecossistema da Apple.

## Sobre o Projeto

O foco central é reproduzir a identidade visual e o layout do Spotify (como telas de detalhes de álbuns, player e navegação), implementando soluções responsivas, limpas e acessíveis.

## Tecnologias e Abordagens

O aplicativo está sendo construído para abranger e comparar as seguintes tecnologias de UI da Apple:

- **SwiftUI embutido no UIKit**: Utilização de componentes modernos, reativos e declarativos do SwiftUI, integrados dentro de uma estrutura base em UIKit (utilizando recursos como `UIHostingController`). O projeto já conta com Views de Álbum, Mini Player e Tab Bar desenvolvidos nesta arquitetura híbrida.
- **View Code**: Criação de interfaces 100% programáticas usando UIKit puro. O objetivo é construir novas telas sem depender do Interface Builder, garantindo controle total sobre Auto Layout (Constraints) e ciclo de vida.
- **Storyboard / Interface Builder**: Construção visual de interfaces para explorar e praticar o uso tradicional de XIBs e fluxos visuais no Xcode.
